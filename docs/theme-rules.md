# Theme Rules

## 基本方針
- ベースは静かな上品系を維持する
- 少しだけスポーティーさを足す
- 観戦オタク向けの熱量は、テーマ選択・勝敗・応援側・マイベストで表現する
- 色や装飾で騒がしくしすぎない
- 今のデザインテイストは維持しつつ、テーマ反映の一貫性を高める

## 色の役割

### Primary
主操作と現在地に限定して使う。

使いどころ:
- 記録するCTA
- 保存ボタン
- 下部ナビのアクティブ状態
- 主要な選択状態
- ホームの最重要アクセント

### Secondary
補助導線と、少し遊びのある差し色として使う。
必ずしもポップな色とは限らず、テーマに対する第2のキャラクターとして扱う。

使いどころ:
- もっと見る
- 詳しく見る
- フィルターや補助操作
- セクションの小アイコン
- サマリーや補助ラベル
- 一部の選択状態

### Accent
マイベストやランキングなど、特別感のある領域専用。
華やかすぎず、落ち着いた特別感を目指す。

使いどころ:
- マイベスト見出し周辺
- 星
- ランキング番号
- ベスト系プレビューの一部
- ランキング作成導線の一部

ルール:
- 広い面には使わない
- 小さく効かせる
- primary と競合させない

### Neutral
背景、カード、本文、非アクティブ状態の土台。

### Status
勝敗やエラーなど、意味が固定された情報に使う。
WIN / LOSE / DRAW は完全な赤緑固定ではなく、テーマの世界観に寄せて調整する。
ただし差は一目で分かるようにする。

## 画面ごとの考え方

### ホーム
- primary: 記録CTA、現在地、最重要アクセント
- secondary: セクション導線、もっと見る、補助アイコン
- accent: マイベスト周辺のみ
- status: WIN / LOSE / DRAW
- neutral: 背景、カード、本文

### 試合一覧
- primary: 主選択や主要アクション
- secondary: 検索補助、フィルター、並び替え
- status: 勝敗ラベル
- neutral: 一覧土台

### 記録フォーム
- primary: 保存、フォーカス、主要選択
- secondary: 補助説明、補助アイコン
- status: バリデーション
- neutral: 入力枠、ラベル、背景

### マイベスト
- primary: 主操作
- secondary: 補助導線
- accent: 特別感の表現
- neutral: 土台

### 振り返り
- primary: 主要数値の一部
- secondary: 補助導線、軽い強調
- status: 勝率文脈
- neutral: 背景、本文

## 下部ナビ
- 全体は少し透明感のある面
- アクティブは小さな背景面を持たせる
- ガラス感は軽めにし、可読性を優先する
- アクティブ表現は、色変更だけでなく面でも示す

## アイコン方針
- 絵文字アイコンは段階的にSVGへ置き換える
- SVGは currentColor で色制御できる形を優先する
- デフォルトアイコンは muted
- アクティブナビアイコンは primary
- セクション補助アイコンは secondary
- 危険操作は danger
- 勝敗文脈は status 系
- 詳細運用ルールは `docs/icon-rules.md` を参照

## 補足
- 観戦テンションは色数の多さではなく、意味づけで出す
- テーマ選択で気分が上がる設計を優先する
- 上品さを崩すほどの派手さは持たせない
